## 实质变化

1. 检索失败只记作检索状态，不再作为政策覆盖证据；不适用地域、尚未生效或生效时间未确认的政策机制只作比较材料，不据此阻断原题。
2. URL 去重保留文章 ID 等内容参数，清除跟踪参数。增加国家统计局、国家发展改革委两个官方目录直连入口，保留原有搜索源；只提取标题、URL、日期，不抓取文章正文。
3. 新增 `draft-check` 和 `draft-review`。确定性篇幅、结构及证据检查与四项内容审查分开，审查记录绑定稿件和证据指纹；版本变化须重新审查，导出后文件变化不能直接记录人工通过，审核后文件变化不能直接登记报送。措辞关键词仅提示上下文复核，不一刀切判空泛。
4. 新增首次合格导出事件。实际周产量按北京时间完成周计算，修订不重复计篇；发现周转化另列。仅有证据通过标志、测试数据或不存在的产物不能用于证明稳定产出。旧稿不补造历史审查或完成时间，也不改已审核、已报送状态。
